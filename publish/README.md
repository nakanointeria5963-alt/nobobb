# 公開の窓口（設置のしかた）

「ホームページ、つくってみる」で作ったものを、**ボタン1つでネットに出せる**ようにするための、小さな窓口です。
**出したページを、あとから消すこともできます。**

一度だけ設置すれば、あとはずっと動きます。**無料です。クレジットカードも要りません。**

---

## 何をするものか

```
職人さんのスマホ                この窓口              GitHub
  [ネットに出す] ──HTMLを送る──→  合言葉をたしかめる ──→ ファイルを置く
  アドレスが出る  ←──アドレス───   （鍵はここに置く）      ↓
                                                 1〜2分後、見られるようになる

  [消す]        ──名前を送る──→  合言葉をたしかめる ──→ ファイルを消す
  一覧から消える ←──消えました──                          ↓
                                                 1〜2分後、見られなくなる
```

**GitHub の鍵（トークン）は、この窓口の中だけに置きます。** アプリの中には入れません。アプリは誰でも中身が見られるページなので、そこに鍵を書くと拾われてしまいます。

**合言葉**を知っている人だけが使えます。**出すのも消すのも、同じ合言葉です。**

---

## 設置の手順

パソコンでやるほうが、ずっと楽です。だいたい20分くらいです。

### 0. 置き場所のリポジトリを作る

お客さんが作ったページを置く場所を、**新しく1つ**作ります。アプリのコードと混ぜないためです。

1. GitHub → 右上の **＋** → **New repository**
2. **Repository name**: `omise`（実際に作ったのはこの名前。ノブさんの置き場所）
3. **Public** のまま
4. **Add a README file** にチェック（空だと Pages が有効にできません）
5. **Create repository**
6. できたら **Settings** → **Pages** → **Source** を `Deploy from a branch`、Branch を `main` / `/ (root)` にして **Save**

独自ドメインにしたいときは、同じ **Pages** の画面で **Custom domain** に `omise.roguepink.com` を入れます。**先に Vercel の DNS に1行足しておいてください**（Name `omise`、Type `CNAME`、Value `roguepink.github.io`）。

### 1. GitHub の鍵をつくる

**このアドレスを開くのが、いちばん早いです。**探さなくて済みます。

```
https://github.com/settings/personal-access-tokens/new
```

> **「Developer settings が見つからない」とき**
> リポジトリの Settings を開いている可能性があります。Developer settings は、
> **アカウントの** Settings（右上のアイコン → Settings → 左のいちばん下）にしかありません。
> 上のアドレスを直接開けば、探す必要はありません。

開いたら、次のように決めます。

| 欄 | 入れるもの |
|---|---|
| **Token name** | `tsukuru-publisher`（なんでもいい） |
| **Expiration** | **1年**（無期限にしない。漏れたときに永久に使えてしまうため） |
| **Repository access** | **Only select repositories** → 手順0で作った `omise` **だけ** |
| **Permissions** → Repository permissions → **Contents** | **Read and write** |
| **Permissions** → Repository permissions → **Metadata** | **Read-only**（自動で付く。そのままでいい） |

`omise` と `mise` は似ています。**`omise` のほうです。**
`Contents` が `Read` のままだと、置くことも消すこともできません。

`Metadata` は GitHub が勝手に付けるもので、外せません。**そのままでいいです。**
中身は「そのリポジトリがあるか、名前は何か」を見るだけで、ファイルの中身は読めません。

決めたら、いちばん下の **Generate token** を押します。

**出てきた文字列をコピーしてください。この画面を閉じると二度と見られません。**
（閉じてしまっても、作り直せば大丈夫です。古いほうは消してください。）

> **この鍵は、誰にも見せないでください。**クロードにも貼らないでください。次の手順で Cloudflare の画面に直接貼ります。

### 2. Cloudflare に窓口を置く

1. https://dash.cloudflare.com/sign-up でアカウントを作る（無料・カード不要）
2. 左のメニューから **Workers & Pages** → **Create** → **Start with Hello World!** → **Deploy**
3. できたら **Edit code**（コードを編集）を押す
4. 出てきたコードを**全部消して**、この隣にある `worker.js` の中身を**まるごと貼り付ける**
5. **Deploy** を押す

### 3. 窓口に、設定を5つ入れる

Worker の画面 → **Settings** → **Variables and Secrets** → **Add**

| 名前 | 種類 | 中身 |
|---|---|---|
| `GH_TOKEN` | **Secret** | 手順1でコピーした鍵 |
| `REPO` | Text | `roguepink/omise` |
| `PASS` | **Secret** | 好きな合言葉（例：`nakano2026`） |
| `ALLOW_ORIGIN` | Text | `https://tsukuru.roguepink.com` |
| `PUBLIC_BASE` | Text | `https://omise.roguepink.com`（独自ドメインを使うとき） |

`GH_TOKEN` と `PASS` は必ず **Secret**（かくす）にしてください。

入れ終わったら **Deploy** をもう一度押します。

### 4. できた窓口のアドレスを控える

Worker の画面の上のほうに、こんなアドレスが出ています。

```
https://＜なにか＞.＜あなたの名前＞.workers.dev
```

**これをクロードに教えてください**（これは鍵ではないので、貼って大丈夫です）。アプリに繋いで公開します。

---

## 設定のいちらん

| 名前 | 要る？ | 中身 |
|---|---|---|
| `GH_TOKEN` | **必須** | GitHub の鍵。Contents の読み書きができるもの |
| `REPO` | **必須** | 置き場所。`owner/repo` の形 |
| `PASS` | **必須** | 合言葉。これを知っている人だけが、出すことも消すこともできる |
| `ALLOW_ORIGIN` | あったほうがいい | このアドレスからの送信だけ受け付ける。無指定だとどこからでも受け付ける |
| `PUBLIC_BASE` | 省略可 | 出来上がりのアドレスの頭。独自ドメインを使うときに入れる |
| `BRANCH` | 省略可 | 置くブランチ。既定は `main` |
| `DIR` | 省略可 | 置くフォルダ。既定は `sites` |
| `MAX_BYTES` | 省略可 | 受け取る上限。既定は 6MB |

## 公開されるアドレス

```
https://omise.roguepink.com/sites/＜ページの名前＞.html
```

置いたあと、公開の処理が走るので、**見られるようになるまで1〜2分**かかります。

同じ名前でもう一度出すと、**上書き**されます（作り直し）。

## 消すとき

アプリの **公開タブ → 🗑 やめたいとき・消したいとき** に、**出したページの一覧**が出ます。消したいものの「消す」を押すだけです。

- 出すときと**同じ合言葉**を使います
- 消しても、**1〜2分は見えたままのことがあります**（すぐには消えません）
- **端末の中の下書きは残ります。**ネットから取り下げるだけです
- 一覧は、下書きを「ぜんぶ消す」しても**消えません**。出したページはネットに残っているので、忘れると消せなくなるためです

---

## 気をつけること

- **合言葉は、渡した人に伝わります。** 広まったと思ったら、`PASS` を変えて Deploy し直してください。すぐ止まります
- **置いたページは誰でも見られます。**置き場所が公開設定のためです。人に見られて困るものは載せないでください
- **鍵の有効期限が切れると、新しく出すことと消すことができなくなります。** すでに出したページは、そのまま見え続けます。新しい鍵を1つ作って `GH_TOKEN` を入れ替えれば直ります（5分）
- Cloudflare の無料枠は 1日10万回です。使い切ることは、まずありません

## うまくいかないとき

| 出るもの | 見るところ |
|---|---|
| 合言葉がちがいます | `PASS` の中身と、アプリに入れた合言葉 |
| 窓口の設定がまだ終わっていません | `GH_TOKEN` `REPO` `PASS` のどれかが未設定 |
| 置けませんでした / 消せませんでした（401 / 403） | 鍵の期限切れ、または置き場所への権限がない |
| 置けませんでした（404） | `REPO` の綴りちがい |
| 何も起きない・つながらない | `ALLOW_ORIGIN` がアプリのアドレスと一致しているか |
| 出したのにページが見つからない | `omise` の **Settings → Pages** が有効になっているか。1〜2分待ったか |
