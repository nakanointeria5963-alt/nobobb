# 公開の窓口（設置のしかた）

「ホームページ、つくってみる」で作ったものを、**ボタン1つでネットに出せる**ようにするための、小さな窓口です。

一度だけ設置すれば、あとはずっと動きます。**無料です。クレジットカードも要りません。**

---

## 何をするものか

```
職人さんのスマホ                この窓口              GitHub
  [ネットに出す] ──HTMLを送る──→  合言葉をたしかめる ──→ ファイルを置く
  アドレスが出る  ←──アドレス───   （鍵はここに置く）      ↓
                                                 1〜2分後、見られるようになる
```

**GitHub の鍵（トークン）は、この窓口の中だけに置きます。** アプリの中には入れません。アプリは誰でも中身が見られるページなので、そこに鍵を書くと拾われてしまいます。

**合言葉**を知っている人だけが使えます。ノブさんが、使ってほしい人にだけ教えてください。

---

## 設置の手順

パソコンでやるほうが、ずっと楽です。だいたい15分くらいです。

### 1. GitHub の鍵をつくる

1. GitHub → 右上のアイコン → **Settings**
2. 左のいちばん下 **Developer settings**
3. **Personal access tokens** → **Fine-grained tokens** → **Generate new token**
4. 次のように決めます
   - **Token name**: `tsukuru-publisher`（なんでもいい）
   - **Expiration**: 1年など（切れたら作り直します）
   - **Repository access**: **Only select repositories** → `nobobb` をえらぶ
   - **Permissions** → **Repository permissions** → **Contents** を **Read and write** に
5. **Generate token** を押す
6. **出てきた文字列をコピーする。この画面を閉じると二度と見られません。**

### 2. Cloudflare に窓口を置く

1. https://dash.cloudflare.com/sign-up でアカウントを作る（無料・カード不要）
2. 左のメニューから **Workers & Pages** → **Create** → **Start with Hello World!** → **Deploy**
3. できたら **Edit code**（コードを編集）を押す
4. 出てきたコードを**全部消して**、この隣にある `worker.js` の中身を**まるごと貼り付ける**
5. **Deploy** を押す

### 3. 窓口に、設定を4つ入れる

Worker の画面 → **Settings** → **Variables and Secrets** → **Add**

| 名前 | 種類 | 中身 |
|---|---|---|
| `GH_TOKEN` | **Secret** | 手順1でコピーした鍵 |
| `REPO` | Text | `nakanointeria5963-alt/nobobb` |
| `PASS` | **Secret** | 好きな合言葉（例：`nakano2026`） |
| `ALLOW_ORIGIN` | Text | `https://nakanointeria5963-alt.github.io` |

`GH_TOKEN` と `PASS` は必ず **Secret**（かくす）にしてください。

入れ終わったら **Deploy** をもう一度押します。

### 4. できた窓口のアドレスを控える

Worker の画面の上のほうに、こんなアドレスが出ています。

```
https://＜なにか＞.＜あなたの名前＞.workers.dev
```

**これをクロードに教えてください。** アプリに繋いで公開します。

---

## 設定のいちらん

| 名前 | 要る？ | 中身 |
|---|---|---|
| `GH_TOKEN` | **必須** | GitHub の鍵。Contents の読み書きができるもの |
| `REPO` | **必須** | 置き場所。`owner/repo` の形 |
| `PASS` | **必須** | 合言葉。これを知っている人だけが公開できる |
| `ALLOW_ORIGIN` | あったほうがいい | このアドレスからの送信だけ受け付ける。無指定だとどこからでも受け付ける |
| `BRANCH` | 省略可 | 置くブランチ。既定は `main` |
| `DIR` | 省略可 | 置くフォルダ。既定は `sites` |
| `MAX_BYTES` | 省略可 | 受け取る上限。既定は 6MB |

---

## 公開されるアドレス

```
https://nakanointeria5963-alt.github.io/nobobb/sites/＜ページの名前＞.html
```

置いたあと、`main` から公開用に写す処理が走るので、**見られるようになるまで1〜2分**かかります。

同じ名前でもう一度出すと、**上書き**されます（作り直し）。

## 気をつけること

- **合言葉は、渡した人に伝わります。** 広まったと思ったら、`PASS` を変えて Deploy し直してください。すぐ止まります
- **置いたページは誰でも見られます。**`nobobb` が公開設定のためです。人に見られて困るものは載せないでください
- **鍵の有効期限が切れると、公開が止まります。** 期限を1年にした場合、来年また作り直しが要ります
- Cloudflare の無料枠は 1日10万回です。使い切ることは、まずありません

## うまくいかないとき

| 出るもの | 見るところ |
|---|---|
| 合言葉がちがいます | `PASS` の中身と、アプリに入れた合言葉 |
| 窓口の設定がまだ終わっていません | `GH_TOKEN` `REPO` `PASS` のどれかが未設定 |
| 置けませんでした（401 / 403） | 鍵の期限切れ、または `nobobb` への権限がない |
| 置けませんでした（404） | `REPO` の綴りちがい |
| 何も起きない・つながらない | `ALLOW_ORIGIN` がアプリのアドレスと一致しているか |
