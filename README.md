# nobobb

小さなアプリを置いておく場所です。いまは2つあります。

| | なにをするもの | 場所 |
|---|---|---|
| **おうちの応急処置** | 家のトラブルが起きたとき、まず何をすればいいかを出す | `index.html` |
| **ホームページ、つくってみる** | えらんでいくだけで、ホームページがその場で出来上がる | `tsukuru/index.html` |

どちらも HTML 1枚で動きます。サーバーも、ログインも、外部への通信もありません。

---

## おうちの応急処置

水漏れ、ブレーカー、ガスのにおい。
困ったときに「まず何をすればいいか」だけを、短くまとめたページです。

### できること

- **困りごとから探す** — 検索と、種類（水まわり / 電気 / 建具 / 壁・床 / におい・カビ / 緊急）でしぼれます
- **3つに分けて表示** — 「まず、これをする」「やってはいけない」「業者を呼ぶ目安」
- **危ないものは目印つき** — ガスのにおい、焦げたコンセント、天井からの水漏れには「すぐ連絡」の赤い印
- **連絡先メモ** — 管理会社・水道・電気・ガスの電話番号を、その端末の中に保存できます

### つくり

`index.html` の1枚だけです。ほかに何も要りません。

- サーバーも、ログインも、通信もなし
- 一度ひらけば、電波が悪くても読めます
- 連絡先メモはその端末の中だけに残ります。どこにも送られません

### なおしかた（文章を直すとき）

`index.html` のなかほどにある `ITEMS` という一覧が、中身のすべてです。
1件がこの形になっています。

```js
{
  cat:"水まわり",          // 種類
  urgent:false,            // true にすると「すぐ連絡」の赤い印がつく
  title:"蛇口から水が止まらない",
  words:"じゃぐち 水漏れ ぽたぽた",   // 検索で引っかけたい言葉
  do:["まずやること", "…"],
  dont:["やってはいけないこと", "…"],
  call:["業者を呼ぶ目安", "…"]
}
```

ここに1件足せば、そのまま画面に出ます。

### 中身について

書いてあるのは、業者が来るまでの間にできることの目安です。
現場と違うところがあれば直してください。

## ホームページ、つくってみる

`tsukuru/index.html`

押していくだけで、上（パソコンなら左）の画面にホームページがどんどん出来上がっていくアプリです。

### えらべるもの

1. **なんのホームページか** — お店・カフェ / 会社・工務店 / 教室・サロン / 自分の作品
   えらぶと、中の文章も丸ごと入れ替わります
2. **名前とひとこと** — 打つそばから反映されます。空のままでも見本が入ります
3. **色** — いちご / みかん / わかば / そら / すみれ / すな の6色
4. **かたちと文字** — 角のまるさ3種類、字の感じ3種類
5. **のせるもの** — 写真 / メニュー・料金 / お客さんの声 / 場所・地図 / お問い合わせ / 営業時間
6. **ならべかた** — 写真が大きい / 文字が中心

### できあがったあと

- **ファイルにして持ち帰る** — `index.html` が1枚ダウンロードされます。そのままホームページとして使えます
- **中身をコピーする** — HTMLをまるごとクリップボードへ

### なおしかた（えらべるものを増やすとき）

`tsukuru/index.html` の上のほうにある、この6つの一覧を書き換えます。

| 一覧の名前 | なにを決めているか |
|---|---|
| `KINDS` | 業種と、そのときに入る見本の文章 |
| `COLORS` | 色（6色） |
| `ROUNDS` | 角のまるさ |
| `FONTS` | 字の感じ |
| `PARTS` | のせられるもの |
| `LAYOUTS` | ならべかた |

たとえば `COLORS` に1行足せば、色のボタンが1つ増えます。
出来上がるページの見た目そのものは、`build()` という部分にまとまっています。
