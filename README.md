# nobobb

小さなアプリを置いておく場所です。いまは2つあります。

| | なにをするもの | 場所 |
|---|---|---|
| **ホームページ、つくってみる** | えらんでいくだけで、ホームページがその場で出来上がる | `index.html`(https://tsukuru.roguepink.com/) |
| **おうちの応急処置** | 家のトラブルのとき、まず何をすればいいかを出す(いまは表に出していない) | `ouchi/index.html` |
| **公開の窓口** | 作ったホームページを受け取って、ネットに出す小さなしかけ | `publish/` |

2つのアプリは、どちらも HTML 1枚で動きます。ログインも要りません。
「ネットに出す」を使うときだけ、`publish/` の窓口に繋がります。

---

## おうちの応急処置

水漏れ、ブレーカー、ガスのにおい。
困ったときに「まず何をすればいいか」だけを、短くまとめたページです。

### できること

- **困りごとから探す** — 検索と、種類（水まわり / 電気 / 建具 / 壁・床 / におい・カビ / 緊急）でしぼれます
- **3つに分けて表示** — 「まず、これをする」「やってはいけない」「業者を呼ぶ目安」
- **危ないものは目印つき** — ガスのにおい、焦げたコンセント、天井からの水漏れには「すぐ連絡」の赤い印
- **連絡先メモ** — 管理会社・水道・電気・ガスの電話番号を、その端末の中に保存できます

### つくり

`index.html` の1枚だけです。ほかに何も要りません。

- サーバーも、ログインも、通信もなし
- 一度ひらけば、電波が悪くても読めます
- 連絡先メモはその端末の中だけに残ります。どこにも送られません

### なおしかた（文章を直すとき）

`index.html` のなかほどにある `ITEMS` という一覧が、中身のすべてです。
1件がこの形になっています。

```js
{
  cat:"水まわり",          // 種類
  urgent:false,            // true にすると「すぐ連絡」の赤い印がつく
  title:"蛇口から水が止まらない",
  words:"じゃぐち 水漏れ ぽたぽた",   // 検索で引っかけたい言葉
  do:["まずやること", "…"],
  dont:["やってはいけないこと", "…"],
  call:["業者を呼ぶ目安", "…"]
}
```

ここに1件足せば、そのまま画面に出ます。

### 中身について

書いてあるのは、業者が来るまでの間にできることの目安です。
現場と違うところがあれば直してください。

## ホームページ、つくってみる

`tsukuru/index.html`

**職人さん・小さな工務店のための、ホームページ作成アプリです。**
電気屋さん、水道屋さん、クロス屋さん、ペンキ屋さん——「ホームページだけ、ちゃんとしたのが欲しい」という人が、えらんで書き込むだけで作れます。

画面は上下に分かれていて、上に「できあがっていくところ」、下に5つのタブ(おみせ / しゃしん / デザイン / のせるもの / 公開)があります。押したそばから上に反映されます。

### できること

- **しごとの種類 8つ** — 電気工事 / 水道・設備 / クロス・内装 / 塗装 / 大工・リフォーム / 左官・タイル / 外構・お庭 / ハウスクリーニング。えらぶと、あいさつ文・仕事と料金・よくある質問・お客さまの声まで、その仕事の見本文章が丸ごと入ります。**自分で書き換えた欄は、業種を変えても消えません**
- **写真** — いちばん上の1枚と、施工例8枚まで。端末の中で自動で軽くしてから入れます(外に送りません)
- **連絡先** — 電話(ページ下部にずっと出る「電話する」ボタン付き)・メール・LINE
- **デザイン** — 見せ方3種 × 色8色+自由な色 × 背景3種 × 文字4種 × 角3種 × 構成2種。明るい色をえらぶと、ボタンの文字は自動で黒になります
- **のせるもの** — あいさつ文 / できること・料金 / 仕事の写真 / たのみ方の流れ / お客さまの声 / よくある質問 / 対応エリア / 営業時間 を、それぞれオンオフ
- **自動保存** — 書いたものはこの端末に残り、次にひらくと続きから。保存コードで別の端末にも移せます

### できあがったら

**公開の窓口（`publish/`）を設置してあるとき**

公開タブに **「ネットに出す」** のボタンが出ます。

1. ページの名前と、**合言葉**を入れる
2. ボタンを押す
3. **アドレスがその場に出ます。**「アドレスを コピー」で控えられます

1〜2分で見られるようになります。同じ名前でもう一度出すと、上書き（作り直し）です。

合言葉を知っている人だけが使えます。誰に使ってもらうかは、合言葉を渡す相手で決まります。

**窓口を設置していないとき**

**「ホームページを保存する」** のボタンだけになります。押すと HTML が1つ保存され、**そのファイルがホームページそのもの**です。LINE やメールにそのまま貼って送れば、受け取った人は押すだけで見られます。

自分の GitHub を持っている人向けに、折りたたみの中で置き場所（`owner/repo`）を指定して手で上げる道も残してあります。

### 窓口を繋ぐには

`publish/README.md` のとおりに設置したあと、`index.html` の上のほうにある

```js
let PUBLISH_API = "";
```

に、できた窓口のアドレスを入れます。空のあいだは、保存する形のままです。

### なおしかた（文章を直すとき）

`index.html` のなかほどにある `ITEMS` という一覧が、中身のすべてです。
1件がこの形になっています。

```js

  urgent:false,            // true にすると「すぐ連絡」の赤い印がつく

  words:"じゃぐち 水漏れ ぽたぽた",   // 検索で引っかけたい言葉
  do:["まずやること", "…"],
  dont:["やってはいけないこと", "…"],
  call:["業者を呼ぶ目安", "…"]
}
```

ここに1件足せば、そのまま画面に出ます。

公開タブでページの名前を決めて「GitHub に出す」を押すと、①できあがったHTMLがダウンロードされ、②GitHub のアップロード画面がひらきます。ファイルをえらんで緑のボタンを押せば、`https://roguepink.github.io/nobobb/＜名前＞.html` で公開されます。

同じ名前でもう一度出すと、上書き(作り直し)になります。

### なおしかた

- 業種や見本文章を足す・直す → `tsukuru/index.html` の `TRADES`
- 色・文字・かたちの選択肢 → `MAIN_COLORS` / `ACCENT_COLORS` / `BG_TONES` / `FONTS` / `RADII`
- できあがるページの見た目 → `build()` 関数
- 出し先のリポジトリ → `REPO` と `BRANCH`
